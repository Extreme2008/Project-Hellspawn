--Wolcome to Project Hellspawn!--

**What is this?**
Project Hellspawn is a learning-focused Unity FPS Prototype designed to teach how to make 90s style Boomer Shooters in Unity, Including 2.5D graphics, UI-based weapons, and more!

it's Free, open, and meant to be dissected.

if you have ever wondered how to make classic 90s FPS type games in Unity, this project is for you!

Built with Unity 6.0

--CURRENT FEATURES--

1. Basic Player movement (walk, jump, crouch, sprint)

2. A Dummy enemy with no AI that plays walk, hurt and death animations

3. the first weapon (Fists)

--HOW TO RUN--
you need Unity 6.0 or higher.
1. Clone this repository

2. open it in Unity Hub

3. Load the scene Assets/Scenes/Main.unity

4. Press Play and shoot away!

--CONTROLS--
Look = Mouse

Walk = W, A, S, D

Jump = Space

Crouch = Left Control

Sprint = Left Shift
